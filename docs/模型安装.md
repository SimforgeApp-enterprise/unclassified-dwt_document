# 模型安装

## 模型创建

可以选择导入试验件，当前仅支持`.stp`格式的模型。在压缩包中已经包含了一个预设的二元翼型`.stp`模型，可以直接导入该模型，进行测试。或者如果自己手中有准备好的二元翼型stp模型，也可以选择导入。
